Build with Regex Studio.

Generate JavaScript regular expressions with Gemini, test expressions against text, or notify your service when a pattern has been generated.

Setup

The base URL is your deployed app, such as https://your-project.vercel.app. For local development, run npm install and npm run dev; the local Node server serves the app at http://localhost:3000.

Configure GEMINI_API_KEY and APP_API_KEY in local .env or Vercel Project Settings → Environment Variables. Keep both values private.

The public playground endpoint has a per-instance limit of 12 generation requests per minute per client IP. Versioned endpoints require a Bearer API key.

Authentication

Send the application key in the Authorization header for every /api/v1/ endpoint. Use it from your server; do not put the key in a browser bundle.

Authorization: Bearer YOUR_APP_API_KEY
Content-Type: application/json

Requests and responses use JSON. CORS preflight is supported for browser integrations. Responses include an Access-Control-Allow-Origin: * header.

Generate a pattern

AUTHENTICATEDPOST/api/v1/generate

Ask Gemini Flash-Lite to return a pattern, JavaScript flags, a short explanation, and examples. Descriptions must be 1–1,000 characters.

{ "description": "Find email addresses with plus aliases" }
{
  "success": true,
  "data": {
    "pattern": "\\b[\\w.+-]+@[\\w-]+\\.[\\w.-]+\\b",
    "flags": "gi",
    "explanation": "Matches common email address formats.",
    "examples": ["alex@example.com", "team+news@site.io"]
  }
}

Public playground route

POST /api/generate accepts the same body without authentication so the website can call it without exposing your application key. It is rate-limited. The versioned endpoint is intended for trusted integrations.

Test an expression

AUTHENTICATEDPOST/api/v1/regex-test

Test a JavaScript regular expression against text. Pattern source is limited to 500 characters; input text is limited to 100,000 characters. At most 1,000 matches are returned.

{
  "pattern": "\\d+",
  "flags": "g",
  "text": "Order 104 ships in 3 days"
}
{
  "success": true,
  "data": {
    "count": 2,
    "matches": [
      { "match": "104", "index": 6, "groups": null },
      { "match": "3", "index": 19, "groups": null }
    ]
  }
}

Flags use JavaScript syntax: d g i m s u v y. Invalid patterns and unsupported flag combinations return 400.

Webhook events

AUTHENTICATEDPOST/api/v1/generate-and-notify

Generate a regex and optionally send a regex.generated event to your public HTTPS endpoint. Delivery waits up to five seconds and reports whether the receiver returned a successful status.

{ "description": "Find ISO formatted dates", "webhookUrl": "https://example.com/hooks/regex" }
{
  "success": true,
  "data": { "pattern": "\\b\\d{4}-\\d{2}-\\d{2}\\b", "flags": "g", "explanation": "Matches ISO dates.", "examples": [] },
  "webhook": { "delivered": true, "status": 200 }
}

Webhook headers include Content-Type: application/json and X-Regex-Studio-Event: regex.generated. The body has this shape:

{
  "id": "event-uuid",
  "type": "regex.generated",
  "createdAt": "2026-11-17T12:00:00.000Z",
  "data": { "pattern": "...", "flags": "g", "explanation": "...", "examples": [] }
}

Example receiver

app.post('/hooks/regex', express.json(), (req, res) => {
  if (req.header('X-Regex-Studio-Event') !== 'regex.generated') {
    return res.status(400).json({ error: 'unsupported_event' });
  }
  console.log(req.body.data.pattern);
  return res.status(200).json({ received: true });
});

POST /api/webhooks/echo is a sample JSON receiver. It responds with 202 Accepted and echoes the received event with a timestamp.

HTTP responses

StatusMeaning
200Request succeeded.
202Echo webhook accepted the request.
400Invalid JSON input, pattern, description, or webhook URL.
401Missing or incorrect API key.
405Unsupported HTTP method; check the Allow header.
429Public generation rate limit or Gemini quota reached.
502Gemini failed or returned an invalid pattern.
503A server environment variable is not configured.

Error bodies use a consistent shape: { "error": "code", "message": "Description" }.

Deploy

  1. Import the project into Vercel or run npx vercel.
  2. Set GEMINI_API_KEY and APP_API_KEY in the project’s environment settings.
  3. Deploy, then open the app and try a prompt and a few patterns.

The regex tester and replacement preview run in a Web Worker in the browser. A slow expression can be interrupted without locking the page. Test strings are not sent to Gemini.
